# Monthly Sales Trend Analysis

## 📊 Project Overview

This project analyzes monthly sales data and visualizes the sales trend using Excel and Python.

The main purpose of this project is to practice date grouping, monthly sales aggregation, chronological sorting, and line chart visualization.

## 🎯 Objectives

- Convert dates into proper date format
- Group sales data by month
- Calculate total monthly sales
- Sort months chronologically
- Create a line chart to identify sales trends

## 🛠️ Tools & Technologies

- Microsoft Excel
- Python
- Pandas
- Matplotlib
- GitHub

## 📁 Project Files

| File | Description |
|---|---|
| `sales_data.csv` | Raw sales transaction data |
| `monthly_sales_summary.csv` | Monthly summarized sales |
| `monthly_sales_analysis.py` | Python analysis script |
| `monthly_sales_analysis.xlsx` | Excel workbook containing data, summary and line chart |

## 📈 Analysis

The sales data is grouped month-wise to understand how sales change throughout the year.

A line chart is used because it is suitable for displaying trends over a period of time.

## 🐍 Python Process

1. Load the CSV dataset using Pandas.
2. Convert the `Order_Date` column into a date format.
3. Group sales by month.
4. Calculate total sales.
5. Create a line chart using Matplotlib.
